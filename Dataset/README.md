# Sample Superstore Dataset

## 📊 Dataset Overview

This folder contains the dataset used for the **Superstore Business Performance & Profitability Analysis** Power BI project.

The dataset contains transactional retail information used to analyze sales, profit, customers, products, regions, categories, discounts, and shipping performance.

## 📌 Dataset Details

| Attribute | Details |
|---|---|
| Dataset Name | Sample Superstore |
| File Type | xlsm |
| Records | 9,994 |
| Fields | 21 |
| Date Range | 2014–2017 |
| Business Domain | Retail |
| Data Granularity | Transaction / Order-Line Level |

## 🎯 Purpose of the Dataset

The dataset was used to perform:

- Sales analysis
- Profitability analysis
- Customer analysis
- Product analysis
- Category and sub-category analysis
- Regional analysis
- Customer segment analysis
- Shipping mode analysis
- Discount and profitability analysis
- Time-based analysis

## 🔄 Usage in Power BI

The dataset was imported into **Microsoft Power BI Desktop** and prepared using **Power Query**.

DAX measures were then used to calculate key business metrics and support dashboard analysis.

## ⚠️ Dataset Note

This is a sample/portfolio dataset used for educational and data analytics purposes. The analysis represents the information available in the dataset and should not be interpreted as real-world company performance.
