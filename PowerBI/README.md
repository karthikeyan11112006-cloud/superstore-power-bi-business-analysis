# Power BI Dashboard

## 📊 Overview

This folder contains the Power BI dashboard developed for the **Superstore Business Performance & Profitability Analysis** project.

The dashboard transforms the Sample Superstore transactional dataset into an interactive business analytics solution.

## 📌 Dashboard Pages

The Power BI file contains four analytical pages:

### 1. Sales Performance Dashboard

Provides an overview of overall business performance.

**Includes:**
- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Profit Margin
- Average Order Value
- Sales trends
- Category analysis
- Regional analysis
- Shipping mode analysis

### 2. Profitability Analysis

Focuses on understanding business profitability.

**Includes:**
- Profit analysis
- Profit Margin
- Profit YoY
- Profit by sub-category
- Sales vs Profit
- Product profitability
- Discount and profitability analysis

### 3. Customer & Segment Analysis

Focuses on customer performance and customer segments.

**Includes:**
- Customer segment analysis
- Sales by segment
- Profit by segment
- Customer performance
- Top 10 customers
- Customer ranking

> The Top 10 Customers funnel-style visual represents ranking/concentration and is not a sales conversion funnel.

### 4. Customer & Product Details

Provides detailed customer and product-level analysis.

**Includes:**
- Customer details
- Product details
- Category
- Sub-category
- Sales
- Profit
- Quantity
- Discount

## ⚠️ Important Note

The dashboard is a **personal portfolio project** created using the Sample Superstore dataset.

The analysis is descriptive and based on the information available in the dataset. Observed relationships between discount and profitability should not be interpreted as proof of causation.
